# hw2_wordcloud 建立文字雲GUI
## 功能
### 1. 英文文字雲

- 輸入英文或讀入純英文的文字檔(.text)
- 選擇輸入的內容裡面要有多少單詞放入文字雲
- 選擇文字雲的主題色
- 生成文字雲

### 2. 中文文字雲

- 輸入中文或讀入文字檔(.text)，可以有英文但不能全是英文
- 選擇輸入的內容裡面要有多少單詞放入文字雲
- 選擇文字雲的主題色
- 生成文字雲

# 實際跑程式

## 首頁

![](首頁.png)

- 能選擇要輸入中文或是英文文章段落做文字雲

## 英文文字雲

![](英文文字雲.png)

- 按回首頁能回去
- 可以選擇要放進文字雲的單詞有多少個
- 可以選主題色
- 輸入或讀入 .txt 
- 按下``產生文字雲``來做文字雲
- 按下``存成圖片``能將文字雲存成 .png 檔

## 中文文字雲

![](中文文字雲.png)

- 功能跟英文文字雲一樣

# 限制

1. 英文文字雲還是會分割單詞不準確，雖然很少發生 (有些單詞中間有空格)
2. 中文文字雲由於是透過別人做的套件分割單詞，因此時常分割得不準確
3. 雖然有條件判斷過濾掉不需要進文字雲的詞彙，但還是容易漏掉
4. 透過單詞出現次數來判定在文字雲內的文字大小，可能會不準
